Installation
1
Télécharger le fichier

Cliquez sur le bouton "Télécharger" ci-dessus pour obtenir le fichier ONKOZ.exe

2
Lancer l'installateur

Double-cliquez sur le fichier téléchargé. Si Windows SmartScreen apparaît, cliquez sur "Informations complémentaires" puis "Exécuter quand même".

3
Connexion à votre compte

L'application s'ouvre directement sur ONKOZ. Connectez-vous avec vos identifiants habituels.

4
Mises à jour automatiques

L'application se met à jour automatiquement en arrière-plan. Un badge dans la barre de titre vous prévient quand une nouvelle version est prête.
